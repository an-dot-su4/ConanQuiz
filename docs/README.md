## ✅ ダブルチェックの方針

### 0. 「照合」と「出典の記録」は別物

- **照合（ダブルチェック）** … 事実を採用する前に、必ず2系統以上の独立した情報源に当たって
  一致を確認しています。食い違ったものは採用せず [`UNVERIFIED.md`](./UNVERIFIED.md) に隔離しました。
- **出典の記録** … `sources` 欄には、読み手がその場で裏を取れるURLを記録しています。
  **2件以上を記録できているのは 458問中 403問**で、残りは1件のみです
  （照合自体は検索横断で行っていますが、確認に使ったページのうち恒久的なURLとして
  記録できたのが1件だった、という状態です）。

`scripts/verify_quiz.py` は出典1件の問題を WARN として一覧に出すので、
2件目を足していく作業のバックログとして使えます。
なお **`conan-121` 以降に追加した問題は出典2件を必須**にしてあり、1件だと ERROR になります。
1件しかないのは初期に作った55問だけです。

### 1. 信頼度ランク

各事実には信頼度ランクを付けています。

| ランク | 意味 | クイズ出題 |
|:---:|---|:---:|
| **A** | 公式（小学館／読売テレビ／劇場版公式／製作委員会リリース）で確認 | ◎ 積極的に出題可 |
| **B** | 日本語版Wikipedia ＋ 独立した報道・専門メディアの2系統以上で一致 | ◎ 出題可 |
| **C** | 情報源が1系統のみ、またはファンWiki由来 | △ 出題は避ける |
| **✗** | 情報源によって記述が食い違う | ✗ **出題禁止**（→ `UNVERIFIED.md`） |

`questions.json` に収録してよいのは **A と B だけ**です。C 以下を入れると検査が ERROR を出します。

### 1-2. 「作中の知識」か「制作の知識」かを必ず決める

問題を追加するときは `knowledge` に `story`（作中）か `production`（制作）を設定します。
「アニメや映画を観ているだけで答えられる問題だけ解きたい」という遊び方を支えるための区分です。

- **story** … 作品の中で描かれていること
- **production** … 声優・監督・脚本・主題歌のアーティスト・公開日・興行収入・作者の経歴など

判定基準の詳細と例は [`06-quiz-data-format.md`](./06-quiz-data-format.md) にあります。
`verify_quiz.py` は未設定を ERROR として検出します。

### 2. 「動く数字」は必ず時点を書く

単行本の巻数、アニメの放送話数、興行収入は時間とともに変化します。
**「◯年◯月時点」を必ず問題文に含める**か、そもそも出題しないでください。
（例：「アニメの累計話数は？」は日が経つと答えが変わるため不適切）

時点依存の問題は `volatile: true` と `asOf` を付けます。アプリは既定でこれらを出題から外します。

### 3. 「一次情報が存在しない」設定は出題しない

キャラクターの誕生日・血液型などは、公式設定が存在しないのにファンサイトで
まことしやかに流布しているケースがあります。実際に**安室透の誕生日**は情報源によって
3通りの記述が見つかったため、出題対象から外しました。

### 4. 「最上級」「最多」を問う設問は特に慎重に

「主題歌を**最も多く**担当したアーティストは？」という問題を作りかけましたが、
**劇場版だけなら B'z（5作）、テレビ主題歌も含めれば倉木麻衣**となり、
問い方次第で答えが変わることが分かったため取り下げました。
最上級表現を使うときは、**範囲を問題文で限定できるか**を必ず確認してください。

### 5. 翻訳・要約による誤りに注意

調査中、自動要約が日本語タイトルを英訳したり、金額の桁（億円 ↔ billion yen）を
取り違えたりする事例が複数ありました。**固有名詞・数値は必ず日本語原文の表記で再取得**して
確認しています。一覧表が概ね正確でも、個別の表記は公式で当たる必要があります
（実例：ある一覧サイトが MISIA の曲名を「ラストダンス**は**あなたと」と誤記していましたが、
公式表記は「ラストダンスあなたと」でした）。

## 問題を追加するときの手順

1. 事実を**2系統以上の独立した情報源**で照合する
2. 食い違ったら採用せず、経緯を [`UNVERIFIED.md`](./UNVERIFIED.md) に記録する
3. `data/questions.json` に追加し、`sources` に**両方のURL**を入れる
4. `python3 scripts/render_quiz.py` → `python3 scripts/verify_quiz.py` → `python3 scripts/build_app.py`

出題前のチェックリストは [`quiz-bank.md`](./quiz-bank.md) の末尾にあります。
