## 1. コードネームの命名規則

組織の構成員は**酒の名前**をコードネームとして与えられます。

> 基本的に **男性は蒸留酒、女性は果実酒** の名前に由来する。

**ランク B**（Wikipedia）

> ⚠️ 「基本的に」という但し書きがついています。クイズにする場合は
> 「**お酒の名前**が由来」という大枠を問う形が安全です。男女の酒種の区別まで
> 断定する問題は、例外の存在を考慮してください。

## 4. APTX4869（アポトキシン4869）

コナンを幼児化させた毒薬。

| 項目 | 内容 | ランク |
|---|---|:---:|
| 読み | **アポトキシン4869** | B |
| 開発者 | **シェリー（宮野志保）**。両親（宮野厚司・エレーナ）の研究を引き継いだ | B |
| 「アポトキシン」の由来 | **アポトーシス**（プログラムされた細胞死）＋トキシン（毒） | C |
| 「4869」の由来 | 語呂合わせで **「シャーロック」**（4＝シ、8＝ハ、6＝ロ、9＝ク） | C |
| 組織内での通り名 | 「**出来損ないの名探偵**」 | C |
| データのパスワード | **"Shellingford"**（コナン・ドイルがホームズに当初つけようとした仮名から） | C |

> ⚠️ **ランクC の項目**（由来・パスワード）はファンWiki系の情報源が中心です。
> 面白いネタですが、**出題する場合は原作の該当巻で裏取りしてから**にしてください。
> 「**開発者は誰か（＝シェリー／宮野志保）**」はランクBなので安全に出題できます。
