## 読売テレビ公式のエピソードDB（全1419件）

キャラクターDBと同じ仕組みで、**全エピソードのデータ**も静的JSONで公開されています。

```bash
curl -s https://www.ytv.co.jp/conan/data/case.json -o case.json
python3 -c "
import json
for c in json.load(open('case.json')):
    x = c['data']
    print(x['episode'], x['title'], x['onair_date'], x['conan_next_hint_text'])
"
```

### ローラー照合の結果

Wikipedia の参照注に書かれた「（アニメ◯◯話「サブタイトル」）」を全記事から機械抽出し、
この公式DBと突き合わせました。

| | 件数 |
|---|---|
| Wikipedia側で話数を特定できたエピソード | 329件 |
| **公式DBとサブタイトルが一致（2系統一致・信頼度A）** | **318件（96.7%）** |
| 表記が揺れて一致判定できなかったもの | 11件 |

一致した318件のうち、Wikipedia での被参照回数（＝作品世界で重要なエピソードほど
何度も引用される）が多い上位から52話ぶんを出題しています。

### ⚠️ 被参照回数は「有名度」の指標としては精度が低い

被参照回数だけで選ぶと、**日常回・フィラー回が混ざります**。
キャラクターの細かい設定（好物・癖・人間関係など）の出典として、
話の規模とは関係なく引用されるエピソードがあるためです。

実際、第246話「網にかかった謎」や第925話「心のこもったストラップ」は
第497話「赤と黒のクラッシュ」より被参照回数が多くなりました。
「原作エピソードかどうか」「何話またぎの長編か」を加えた総合スコアも試しましたが、
やはり有名度とはきれいに相関しませんでした。

**そこで難易度は手作業で振り分けています。**
