## 2. 怪盗キッド

| 項目 | 内容 | ランク |
|---|---|:---:|
| 本名 | **黒羽快斗**（くろば かいと） | A |
| 表の顔 | **江古田高校 2年生** | B |
| 父 | **黒羽盗一**（世界的天才マジシャン／**初代怪盗キッド**）。8年前に失踪 | B |
| 声優 | **山口勝平**（＝工藤新一と同じ） | A |
| 出典元の作品 | 青山剛昌の別作品『**まじっく快斗**』 | A |
| コナン初登場 | 単行本 **16巻**（アニメは第76話「**コナンVS怪盗キッド**」） | C |

### 「キッド（KID）」という名前の由来 ★クイズ最有力ネタ

正式な呼称はもともと「**怪盗1412号**」でした。

新聞記者が走り書きした「**1412**」を、**工藤優作**（新一の父）が「**KID**」と読み間違えたことから、
「怪盗キッド」という呼び名が広まった——という設定です。

**ランク B**（劇場版名探偵コナン公式X／pixiv百科事典／まじっく快斗Wikipedia で一致）
※アニメ『まじっく快斗1412』のタイトルも、この「1412」に由来しています。

## 4. 名前の由来まとめ（一覧）

| 対象 | 由来 | ランク |
|---|---|:---:|
| **江戸川コナン** | 江戸川乱歩 ＋ アーサー・コナン・ドイル | B |
| **灰原哀** | コーデリア・グレイ（灰）＋ V・I・ウォーショースキー（I＝あい） | B |
| **怪盗キッド** | 「怪盗1412号」の「1412」を工藤優作が「KID」と誤読 | B |
| **黒ずくめの組織のコードネーム** | お酒の名前 | B |
| **毛利小五郎** | 姓＝**モーリス・ルブラン**（『アルセーヌ・ルパン』の作者）／名＝**明智小五郎**（江戸川乱歩の名探偵） | B |
| **「眠りの小五郎」** | うつむいた状態で淡々と推理する姿が、眠っているように見えることから | B |

**トリビア：** 毛利小五郎の名前は、**フランスの作家（モーリス・ルブラン）と日本の名探偵（明智小五郎）**の
組み合わせです。江戸川コナン（江戸川乱歩＋コナン・ドイル）と同じく、**実在の推理作家・架空の名探偵から
1文字ずつ取る**というのが青山作品の命名パターンになっています。
（ランク B：Wikipedia「毛利小五郎」＋複数の解説記事で一致）
