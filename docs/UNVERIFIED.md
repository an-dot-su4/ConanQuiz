### 声優問題の誤答に、性別の合わないキャストが混じることがある

声優を問う問題の誤答は、同じキャスト表から機械的に選んでいます。そのため
「ウォッカの声は？」の誤答に女性声優が並ぶなど、消去法で絞れてしまうことがあります。
事実としては誤りではないので出題は止めていませんが、難易度は下がります。
気になる場合はアプリの編集タブで誤答を差し替えてください。

### 劇場版の舞台を問う問題を作らなかった理由

第1作の「西多摩市」、第5作の「西多摩市」など**架空の都市**が舞台の作品が多く、
「モデルになった実在の場所」と「作中の舞台」を混同した解説が各所に見られます。
確実に実在の地名が舞台と確認できた第26作（八丈島近海）・第27作（函館）・
第29作（神奈川）以外は、**出題を見送りました**。

### 警察の階級問題に出る「包含関係」警告について

`verify_conan_quiz.py` は「正解が誤答の部分文字列になっていないか」を検査しますが、
**警察の階級**（警部 / 警部補、警視 / 警視正 / 警視長）は文字列として包含関係にあるため、
この検査が WARN を出します。これらは同じ階級体系から選んだ正当な選択肢なので、
**誤検出として許容**しています（WARN は出題を止めません）。

### 検査で機械的に防いでいること

`scripts/verify_quiz.py` が、`confidence` が C 以下の問題の混入、出典欠落、
正解と誤答の包含関係（消去法で当たる問題）、正解位置の偏りなどを自動検出します。
`quiz-bank.md` と `questions.json` のずれも検査対象です。
