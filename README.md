# コナン捜査ファイル

『名探偵コナン』の**非公式ファンクイズ**です。出典付きでダブルチェックした **458問** から、
難易度・カテゴリを選んでランダムに出題します。

> ⚠️ **このリポジトリは有志が作成した非公式のファンプロジェクトです。**

## 遊ぶ

**<https://an-dot-su4.github.io/ConanQuiz/>**

[`index.html`](./index.html) は問題データを埋め込んだ単体HTMLなので、
ダウンロードしてブラウザで直接開いても動きます。

### 共有コードで、同じ問題に一緒に挑戦できます

出題設定の「共有コード」に同じコードを入れて同じ設定で始めると、
**誰が挑戦してもまったく同じ問題・同じ選択肢の並び**になります（マインクラフトのシード値と同じ仕組み）。
空欄なら毎回ランダムです。

出題中に表示される「リンクをコピー」を押すと、コードと設定を含んだURLがコピーされます。
そのURLを開いた人は設定が復元された状態から始められます。

```
https://an-dot-su4.github.io/ConanQuiz/?code=ND6422&d=advanced&c=movies&n=20
```

> ℹ️ 問題データを更新すると、同じコードでも出題内容が変わります。
> 一緒に解くときは、同じ時期に挑戦してください。

カテゴリは8つあり、**複数選べます**（チップの数字は収録数）。出題数は 5・10・20・30・50問 から選べます。

### カテゴリの偏りと「均等に出題」

収録数はカテゴリごとに大きく違います。

| カテゴリ | 問数 | 全体比 |
|---|---:|---:|
| 主題歌 | 158 | 34.5% |
| 劇場版 | 147 | 32.1% |
| 登場人物 | 107 | 23.4% |
| 黒ずくめの組織 | 14 | 3.1% |
| 作品の基本 | 11 | 2.4% |
| テレビアニメ | 8 | 1.7% |
| 由来・トリビア | 7 | 1.5% |
| 道具・発明品 | 6 | 1.3% |

そのまま無作為に引くと上位3カテゴリで9割を占めてしまうため、
**「選んだカテゴリから均等に出題する」を既定でオン**にしています。
50問引いたときの実測は次のとおりです。

| | 上位3カテゴリの割合 |
|---|---|
| 均等オフ（収録数に比例） | 44 / 50問（88%） |
| **均等オン** | **19 / 50問（38%）**（8カテゴリに6〜7問ずつ） |

収録数どおりの比率で出したい場合はオフにしてください。

## 「間違ったクイズを作らない」ための仕組み

このプロジェクトの最優先事項は、**誤った知識を出題しないこと**です。

### 1. 採用前に2系統以上で照合する

すべての事実は、**独立した2系統以上の情報源**に当たって一致を確認してから採用しています。
食い違ったものは採用せず、経緯を [`docs/UNVERIFIED.md`](./docs/UNVERIFIED.md) に記録しました。

実際に見送った例：

- **安室透の誕生日** — 情報源によって7月31日 / 8月26日 / 不明の3通り
- **目暮十三の階級** — 小学館公式は「警視」、他2系統は「警部」（作中で昇進した可能性）
- **劇場版第9・11・15・16作の脚本** — Wikipedia と他ソースで食い違い
- **「主題歌を最も多く担当したアーティスト」** — 劇場版のみなら B'z、TV主題歌を含めれば倉木麻衣となり、問い方で答えが変わる

### 2. 信頼度ランクを付ける

| ランク | 意味 | 収録 |
|:---:|---|:---:|
| **A** | 公式（小学館／読売テレビ／劇場版公式など）で確認 | ◎ |
| **B** | Wikipedia ＋ 独立したメディアの2系統以上で一致 | ◎ |
| **C** | 1系統のみ、またはファンWiki由来 | ✗ 収録しない |

### 3. 出典URLを問題ごとに記録する

各問題に出典URLを持たせ、アプリの解答画面から直接たどれます。
`conan-121` 以降は **2件以上を必須**（検査でエラー）にしています。
初期に作った55問は照合はしたもののURLを1件しか記録できておらず、
検査が警告として一覧に出すため、追記のバックログとして使えます。

### 4. 出題を避けるべきものを決めておく

「動く数字（巻数・話数・興行収入）は時点を明記する」「公式設定が存在しない誕生日などは出題しない」
「『最多』のような最上級表現は範囲を限定できるときだけ使う」といった編集方針を
[`docs/README.md`](./docs/README.md) にまとめてあります。問題を追加する前にご一読ください。

### 5. 機械的に検査する

```bash
python3 scripts/verify_quiz.py
```

- `id` の重複・書式、問題文の重複
- 選択肢がちょうど4つで重複がないか
- `choices[answerIndex] == answer` か
- 信頼度が A / B のみか
- 出典が1件以上あり http(s) URL か（新規分は2件必須）
- `meta` の集計値が実データと一致するか
- **正解位置に偏りがないか**（ランダム出題での位置バイアス検出）
- **正解が誤答の部分文字列になっていないか**（消去法で当たる問題の検出）
- `docs/quiz-bank.md` が `data/questions.json` と同期しているか

## リポジトリ構成

| パス | 内容 |
|---|---|
| [`index.html`](./index.html) | **ビルド成果物**。GitHub Pages が配信するアプリ本体 |
| [`data/questions.json`](./data/questions.json) | **正本**。全458問の機械可読データ |
| [`src/template.html`](./src/template.html) | アプリのソース（問題データは差し込み） |

### 問題の編集にはパスワードが必要です

「問題を編集」タブはパスワードで保護してあります（タブに 🔒 が付いているときはロック中）。
一度解除するとこのブラウザでは記憶され、ツールバーの「ロックする」で再びロックできます。

> ⚠️ **これは簡易的な制限です。**
> サーバを持たない静的サイトなので、判定はブラウザ内で完結します。
> パスワードは平文ではなく SHA-256 のハッシュだけを埋め込んでいますが、
> 本気で調べる人を止められるものではありません。
>
> ただし**実害はほぼありません**。編集内容は各自の `localStorage` に保存されるだけで、
> 公開サイトの問題データは書き換わりません。問題を実際に変更できるのは、
> このリポジトリに push できる人だけです。

パスワードを変えるときは、新しい文字列の SHA-256 を求めて
`src/template.html` の `EDIT_PASS_SHA256` を差し替え、`python3 scripts/build_app.py` で再ビルドします。

```bash
python3 -c "import hashlib,sys;print(hashlib.sha256(sys.argv[1].encode()).hexdigest())" '新しいパスワード'
```
| [`docs/`](./docs/) | 調査資料・問題一覧・出題禁止リスト（[方針は `docs/README.md`](./docs/README.md)） |
| `scripts/` | ビルド・生成・検査スクリプト |

`data/questions.json` が唯一の正本で、`index.html` と `docs/quiz-bank.md` はそこから生成されます。

### 問題を直す手順

```bash
# 1. data/questions.json を編集する（アプリの「問題を編集」タブから書き出すこともできます）
python3 scripts/render_quiz.py   # 2. docs/quiz-bank.md を再生成
python3 scripts/verify_quiz.py   # 3. 整合性を検査
python3 scripts/build_app.py     # 4. index.html を再ビルド
```

main に push すると GitHub Pages に自動で反映されます。
Pull Request では CI が検査とビルドの同期を確認します。

データ形式の詳細と、他のアプリから読み込むための実装例は
[`docs/06-quiz-data-format.md`](./docs/06-quiz-data-format.md) にあります。
